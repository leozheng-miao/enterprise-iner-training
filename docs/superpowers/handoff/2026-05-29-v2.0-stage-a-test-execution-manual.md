# IRP v2.0 Stage A —— 测试执行手册（亲自执行版）

> 版本：Stage A 已合并到 `main`（merge commit `9f56efa`）
> 日期：2026-05-29
> 用法：**你自己逐步执行**。每一步给出「调用/命令」「参数」「预期结果」，并留「实际结果 ☐」给你勾对。
> 重要前提：**Stage A 不暴露任何 HTTP 接口**（Agent 尚未接入网关，那是 Stage B）。因此本手册的"调用"是：Maven 命令、应用启动、MySQL 查询、以及一段可直接粘贴运行的"真实调用冒烟测试"。**无法也不需要用 Postman。**

## 阶段 4 —— 真实调用冒烟（可选，最接近"调接口"）

> 这是 Stage A 唯一能"真正调一次大模型"的方式：临时写一个 `@SpringBootTest`，注入网关直接调用。需真实 `DASHSCOPE_API_KEY` + 外网。

### 步骤 4.1 新建临时冒烟测试文件
- **调用**：把以下内容存为 `src/test/java/com/leo/enterpriseinertraining/llm/SmokeManualTest.java`：
```java
package com.leo.enterpriseinertraining.llm;

import com.leo.enterpriseinertraining.llm.api.*;
import org.junit.jupiter.api.Disabled;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.context.SpringBootTest;

import static org.assertj.core.api.Assertions.assertThat;

@SpringBootTest
class SmokeManualTest {

    @Autowired LLMGateway gateway;

    @Test
    @Disabled("手动冒烟：需真实 DASHSCOPE_API_KEY + 外网，去掉 @Disabled 再跑")
    void chat_realDashScope_returnsNonEmptyContent() {
        ChatResponse r = gateway.chat(
            AgentRole.RESEARCHER,
            ChatRequest.builder()
                .systemText("你是简洁的助手")
                .userText("用一句话介绍人工智能")
                .build(),
            0L);

        System.out.println("内容 = " + r.content());
        System.out.println("模型 = " + r.model());
        System.out.println("token = " + r.promptTokens() + " / " + r.completionTokens());

        assertThat(r.content()).isNotBlank();
        assertThat(r.promptTokens()).isGreaterThan(0);
    }
}
```

### 步骤 4.2 运行冒烟
- **调用 / 参数**（先去掉 `@Disabled`，确保 `DASHSCOPE_API_KEY` 已 export）：
```bash
./mvnw -Dtest=SmokeManualTest test
```
- **预期结果**：
  - 控制台打印 `内容 = ...`（非空中文一句话）、`模型 = qwen...`、`token = N / M`（均 > 0）；
  - 测试 PASS。
- 实际结果：☐

### 步骤 4.3 清理
- **调用**：验证完删除 `SmokeManualTest.java`（它是临时文件，不要提交）。
